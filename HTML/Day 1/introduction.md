# 📌 Introduction to HTML
### 📖 What is HTML?
HTML (HyperText Markup Language) is the standard language for creating web pages. It structures web content using elements such as headings, paragraphs, links, images, and more. It works alongside CSS for styling and JavaScript for interactivity.

#### 🛠 Practical Example:
```html
<!DOCTYPE html>
<html>
<head>
    <title>My First Web Page</title>
</head>
<body>
    <h1>Welcome to HTML</h1>
    <p>This is a basic example of an HTML page.</p>
</body>
</html>
```

---

### 📖 History & Evolution of HTML
- **1989:** Tim Berners-Lee invented HTML.
- **1991:** First HTML specification with 18 tags.
- **1995:** HTML 2.0 introduced forms and tables.
- **1997:** HTML 4.0 introduced CSS support.
- **2014-Present:** HTML5 introduced semantic tags, multimedia support, and offline storage.

#### 🛠 Practical Example of HTML5 Features:
```html
<!DOCTYPE html>
<html>
<head>
    <meta charset="UTF-8">
    <meta name="viewport" content="width=device-width, initial-scale=1.0">
    <title>HTML5 Example</title>
</head>
<body>
    <header>
        <h1>Welcome to HTML5</h1>
    </header>
    <section>
        <p>HTML5 introduced semantic elements like <code>&lt;section&gt;</code> and <code>&lt;article&gt;</code>.</p>
    </section>
</body>
</html>
```

---

### 📖 Basic Structure of an HTML Document
Every HTML page follows a specific structure:
1. `<!DOCTYPE html>` - Defines the document type.
2. `<html>` - Root element of the document.
3. `<head>` - Contains metadata, title, and links to stylesheets.
4. `<body>` - Contains visible content of the webpage.

#### 🛠 Practical Example:
```html
<!DOCTYPE html>
<html>
<head>
    <title>Basic HTML Structure</title>
</head>
<body>
    <h1>Hello, World!</h1>
    <p>This is a paragraph inside the body.</p>
</body>
</html>
```

### 📖 HTML Editors (VS Code, Sublime, Notepad++)
To write and edit HTML, you need a code editor:
- **VS Code:** Free, popular, and has extensions for web development.
- **Sublime Text:** Lightweight and fast with a clean interface.
- **Notepad++:** Simple, open-source, and good for beginners.

#### 🛠 Steps to Write HTML in VS Code:
1. Install **VS Code** from [https://code.visualstudio.com](https://code.visualstudio.com).
2. Open **VS Code**, create a new file, and save it as `index.html`.
3. Start writing HTML code and preview in a browser.
