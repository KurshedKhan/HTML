# **Detailed Explanation of Formatting Tags in HTML**

Formatting tags in HTML are used to style text, making it bold, italic, underlined, emphasized, or structured differently for better readability. Below is a detailed explanation of various formatting tags along with examples.

## **1. Bold (`<b>`), Strong (`<strong>`)**

### **▶ `<b>` (Bold)**
The `<b>` tag makes text bold but does not add extra importance to it.

It is used for stylistic purposes.

🔹 **Example:**

```html
<p>This is a <b>bold</b> text.</p>
```

🔹 **Rendered Output:**  
This is a **bold** text.

### **▶ `<strong>` (Strong)**
The `<strong>` tag also makes text bold but adds semantic importance.

It indicates that the text is important.

🔹 **Example:**

```html
<p>This is a <strong>very important</strong> message.</p>
```

🔹 **Rendered Output:**  
This is a **very important** message.

---

## **2. Italic (`<i>`), Emphasis (`<em>`)**

### **▶ `<i>` (Italic)**
The `<i>` tag is used to italicize text for **styling or decorative purposes**.

Often used for technical terms, foreign words, or phrases.

🔹 **Example:**

```html
<p>This is an <i>italic</i> word.</p>
```

🔹 **Rendered Output:**  
This is an *italic* word.

### **▶ `<em>` (Emphasis)**
The `<em>` tag also makes text italic but adds emphasis to it.

Search engines and screen readers give it more importance.

🔹 **Example:**

```html
<p>Please <em>do not forget</em> to submit the form.</p>
```

🔹 **Rendered Output:**  
Please *do not forget* to submit the form.

---

## **3. Underline (`<u>`)**

The `<u>` tag underlines text, mainly for stylistic purposes.

It is **not recommended for links**, as hyperlinks already use underlining.

🔹 **Example:**

```html
<p>This is an <u>underlined</u> text.</p>
```

🔹 **Rendered Output:**  
This is an **underlined** text.

---

## **4. Subscript (`<sub>`) & Superscript (`<sup>`)**

### **▶ `<sub>` (Subscript)**
The `<sub>` tag is used to display **smaller text below the baseline**.

Commonly used in chemical formulas and mathematical expressions.

🔹 **Example:**

```html
<p>The chemical formula of water is H<sub>2</sub>O.</p>
```

🔹 **Rendered Output:**  
The chemical formula of water is H₂O.

### **▶ `<sup>` (Superscript)**
The `<sup>` tag is used to display **smaller text above the baseline**.

Often used in mathematical exponents and ordinal numbers.

🔹 **Example:**

```html
<p>Mathematical power: 5<sup>2</sup> = 25</p>
```

🔹 **Rendered Output:**  
Mathematical power: 5² = 25

---
